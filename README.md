Ciao! My name is Marco Impellizzeri

Full Stack Web Developer
------------------------

I'm a Full Stack Web Developer with years of hands-on experience building a wide range of web projects — from business web apps and e-commerce platforms to landing pages and mobile applications. What drives me every day is the challenge of turning ideas into polished, functional digital products, working comfortably across both frontend and backend.

I started my journey through an intensive Full Stack bootcamp, and since then I've been continuously growing as part of the development team at Studio Il Granello, where I've had the chance to work on diverse real-world projects that pushed me to level up my skills across the full stack.

I'm fluent in Vue.js, Nuxt, React, React Native, Laravel, and Node.js, and I love combining clean UI with solid backend logic. I also actively integrate AI tools like Claude, Gemini, and ChatGPT into my workflow — using them to move faster, think sharper, and build better.

I'm always curious, always learning, and always looking for the next challenge.

* 🌍  I'm based in Emilia Romagna, Italy
